# EduNexus - User Manual
1. **Register** with name, email, password, profession, course and interface language; then log in. Your profile shows in the left sidebar.
2. **Theme / language**: sun/moon button and language box at the bottom of the sidebar (also in Settings).
3. **Learning Assistant**: type or use the mic. Reply language follows your question (Hindi, English, Hinglish, ...). Say "explain in English" to override. Attach a library document with the paperclip selector. Rename/delete chats on the left.
4. **Voice Assistant**: tap the orb or *Start mic*, check/edit the recognised text, press *Send*. Use Mute, Stop speaking and Repeat. Needs Chrome/Edge and microphone permission; otherwise type.
5. **My Library**: upload PDF/DOCX/TXT (max 15 MB), search, filter, rename, delete. **Open** shows the reader with extracted text, summary, notes, flashcards, MCQs and a question box. Scanned PDFs are flagged "Needs OCR".
6. **Document Summarizer**: choose a document, mode (short/medium/detailed) and language; Copy or Download results.
7. **Study Tools / Writing Studio**: pick a tool, type or dictate, generate. Writing Studio has grammar, rewrite, simplify, expand, shorten, tone, headings and bullets.
8. **Study Planner**: add tasks (voice allowed), day/week/month views, mark complete, timer with a break reminder every 25 minutes.
9. **Progress & Analytics**: real study time, tasks, documents, AI sessions. New accounts see empty states.
10. **Backup**: copy `edunexus.db` and the `uploads/` folder while the server is stopped.
11. **Feedback**: open "Feedback" in the sidebar. Give an overall star rating (required), rate each part with 1-5 yellow stars, and tell us what you liked, what felt wrong, what to improve, and which features to add.
12. **Study Tools / Assistant with documents**: use "Upload document" (or pick a file from My Library) to run a tool on a whole document, or to chat about it.
